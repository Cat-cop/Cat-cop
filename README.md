Домашние серверы, Telegram-боты, Minecraft, автоматизация

Держу собственную домашнюю инфраструктуру: **Home Assistant, Matrix, Navidrome,
Minecraft-серверы, локальные LLM и кучу Telegram-ботов**.

Большинство вещей запускается у меня дома — стараюсь использовать облака только там,
где это необходимо т.к. корпа не сделала нормального решения.


- 🤖 **ChatGPT-driven development** — использую ChatGPT почти для всего, потому что сам в коде разбираюсь примерно на уровне «ну чёт могу на питоне, могу там чёт сам попробовать отредактировать, но вот написать с нуля... ууу....».
